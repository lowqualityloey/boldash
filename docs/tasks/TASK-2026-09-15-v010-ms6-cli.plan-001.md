## 3. Slices (each: thin vertical → four-stage gate → commit; stop-condition = any gate failure)

### S1 — kernel + envelope + `init` (AC-1, AC-2, AC-3, AC-4 partially)

- `src/cli/argv.ts`: hand-rolled parser per ADR-0004 — global flags, subcommand routing, `--help`/`--version`; unknown flag → `USAGE` exit 2 envelope. No dependencies.
- `src/cli/output.ts`: envelope `{ok:true,data}` / `{ok:false,error{code,message,field?,suggestion?}}` (cli-reference §Output Contract); `--format json` = stable key order, no ANSI, no color under `--no-color`; human format minimal table/line.
- `src/shared/errors.ts` **code→exit map as tested constant** (RFC §3.5): every code in `docs/errors.md` → its exit class; each code ships with a test that produces it.
- `src/cli/commands/init.ts`: scaffold-only tree (R3): `.boldash/{state/{project,tasks,decisions,evidence}.json, config.yaml, evidence/, workflows/, policies/}` — state files written through the State Engine bootstrap (no direct `fs.writeFile` of state JSON); `--force` re-init guard → exit 2; idempotent.
- `src/cli/main.ts` + `bin` wiring in `package.json` (`npm run build` → `dist/`); TLD-await allowed only in entry point.
- **Tests**: golden integration on temp fixture repos (`spawn` built CLI): init tree + stdout schema-validation vs envelope; argv unit branches; help line budgets (root ≤200, per-cmd ≤40).

## 4. Cross-cutting invariants (every slice)

1. CLI imports only `src/core/*/index.ts` public surfaces; `src/core/` never imports CLI/adapters; no `src/adapters/` import (ADR-0005 trim: generic host only).
2. ajv@8.20.0 sole runtime dep — YAML (`config.yaml`) is **written** as a literal scaffold, never parsed by core (parse, if ever needed, is MS-8's problem).
3. Every JSON stdout shape validated against its schema in tests (RFC §1.2 schema discipline).
4. Read current bytes before touching; post-write re-read asserts; `date -u` stamps; no push beyond the GO-MS6 per-instance authorization for its commits; **silence ≠ authorization**.
5. ESM, strict TS, no `any`, named exports, TSDoc on every public function.
